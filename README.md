A plugin that adds a helper component for AI Sight Perception. This allows you to specify if AI can see the thing with the component.

1: Add the 'AISightTargetComponent' to the actor you want to be seen by the AI Sight Perception.

2: Select the desired 'AISightTargetStrategy' class you'd like to use.

3: Create a child of the 'AISightTargetStrategy' class and override the function inside.
